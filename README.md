# 🏥 MediBooker — Hospital Management System (MERN Stack)

**MediBooker** is a complete **Hospital Management & Appointment Booking Web Application** developed using the **MERN Stack (MongoDB, Express.js, React.js, Node.js)**.

This digital system connects **patients, doctors, and hospital administrators**, making healthcare services faster, easier, and more secure. From booking appointments to managing hospital data, MediBooker brings everything under one platform.

---

## 🚀 Features

### 👨‍⚕️ Patient Panel
- Register/Login using JWT Authentication
- Book & cancel appointments
- View doctor profiles & availability
- Track booking history
- Access personal details & records

### 🩺 Doctor Panel (Optional Extension)
- View scheduled appointments
- Update availability timings
- Check relevant patient information

### 🛠️ Admin Panel
- Dashboard analytics
- Manage doctors & users
- Approve/Remove doctors
- View all appointments
- Manage hospital data & resources

### 🔐 Security & Storage
- JWT-based authentication
- Password hashing using bcrypt
- Secure cookies & validation
- Cloud image upload (Cloudinary)
- Role-Based Access (Patient / Admin / Doctor)
